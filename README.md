# 🍔 Cravings – Food Delivery Web Application

Cravings is a Java-based food delivery web application developed using JSP, Servlets, JDBC, MySQL, HTML5, and CSS3.

The application allows users to register and log in, browse restaurants and menus, add food items to a cart, place orders, and view their order history.

## ✨ Features

- User registration and login
- Restaurant listing
- Restaurant menu browsing
- Add food items to cart
- Update and remove cart items
- Checkout and delivery details
- Place food orders
- View order history
- View order details
- User profile management
- Password encryption using jBCrypt
