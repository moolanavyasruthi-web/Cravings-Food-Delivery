# 🍔 Cravings – Food Delivery Web Application

Cravings is a Java-based food delivery web application developed using JSP, Servlets, JDBC, MySQL, HTML5 and CSS3.

The application allows users to register, log in, browse restaurants and menus, add food items to a cart, place orders and view their order history.

### Backend
- Java
- J2EE
- Servlets
- JSP
